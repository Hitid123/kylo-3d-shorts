# Script formulas

Numbers below come from public channel pages (Nov 2026) and a frame-by-frame analysis of ZackD Films shorts published by a creator — treat them as working targets, not laws.

| Format | Typical length | Words | Example titles (pattern) |
|---|---|---|---|
| Build chain ("How X becomes Y") | 60–78 s | 150–200 | How a Hole Becomes a Bunker · How a Cave Becomes a Home · How a Tree Becomes a Treehouse |
| "How you invented X" | 32–51 s | 85–135 | How you invented the door · How you invented air conditioning |
| What if / explainer (realistic, ZackD-like) | 25–40 s | 70–110 | What happens if you hold in a sneeze · What if you never blinked |

Speech rate: ~2.6–2.8 words per second, calm and even (ZackD median measured at 2.77 w/s). One beat ≈ one sentence ≈ 2–5 s.

## 1. Build chain (the main format of this skill)

```
If you [simple action] [in an everyday place], you have a [thing].           ← hook: one sentence, result first
But [concrete failure you can show].                                         ← problem
So you [fix with a specific object or material].                             ← fix = new object on screen
(This is a [name of the part].)                                              ← optional naming beat, label pops up
... repeat But/So 4–7 times, each problem caused by the previous fix ...
[Final small comforts: 2–3 items in one line.] Congratulations, you have built a [thing].   ← payoff
```

Why it works: every "But" opens a question, every "So you" closes it with something new appearing — the viewer never gets a quiet second. Problems escalate (physics → water → air → power → safety). The payoff line mirrors the hook, so the loop back to the start feels natural.

Rules:
- Each "So you" introduces exactly one object/material the build script can drop, pour, grow or slide in.
- Problems must be physical and showable: crushing, leaking, flooding, freezing, darkness, no air, collapse, heat.
- Use real materials and real reasons (rebar because concrete cracks under tension, a sump pump because groundwater rises). Check every claim; if unsure, soften ("most builders...") or cut it.
- Second person, present tense, no filler, no jokes that need a pause.
- 7–10 beats. Stop before it drags: if a fix needs explaining, it is the wrong fix for this format.

Original example (included as `examples/pool`):
```
If you dig a hole in your backyard and fill it with water, you have a pool.
But the walls are just mud, and they cave in by the next morning.
So you pour thick concrete walls with steel bars inside.
But in a week, the water turns green.
So you add a pump and a filter. This is a filter.
But the water is freezing cold.
So you put a heater right next to it.
Add a ladder and some lights. Congratulations, you have built a pool.
```

Idea bank (places × goals): hole → bunker / cellar / well / pond / root cellar; tree → treehouse / zipline; shipping container → home / greenhouse / pool; garage → gym / panic room; roof → garden / observatory; cave → home; boat → houseboat; hill → hobbit house; river → waterwheel power; empty lot → skate park. Pick ideas where every step is physically visible in a cross-section.

## 2. "How you invented X"

```
You're [a caveman / living 10,000 years ago] and [problem in one line].
So you [first primitive fix]. But [it fails].
So you [better fix]... 
That's how you invented [X].
```
Shorter (32–51 s). The title must contain "you" — on one channel the switch from "How does X work" to "How you invented X" moved shorts from ~10–100K views to millions (public channel data, Oct 2026).

## 3. "What if" / body explainer (realistic look)

```
What happens if you [everyday action pushed too far]?            <- hook = the question, first frame already mid-action
You [do the first step]. [Second step, physical and visible].   <- the viewer does it with the character
But [the hidden mechanism]. So [it escalates].                  <- cut inside the body / object (X-ray, macro, cutaway)
In [year], [a real person] did exactly that. [What happened.]   <- optional real case = credibility (verify it!)
[Consequence, shown inside again.] [What doctors/experts did.]
So [the one-line takeaway].                                      <- payoff, back to the calm real view
```
Example (`examples/whatif`, facts from BMJ Case Reports 2018):
```
What happens if you hold in a sneeze?
You pinch your nose and shut your mouth.
But the sneeze still comes, and the air has nowhere to go.
So the pressure in your throat spikes in an instant.
In 2018, a 34-year-old man in England did exactly that.
He felt a pop in his neck.
He had torn the back of his throat, and air leaked into his neck and chest.
Doctors fed him through a tube while it healed.
So when a sneeze comes, just let it out.
```
Rules:
- 25–40 s, 70–110 words, 8–10 beats. Second person until the real case, then third person for the case.
- Alternate real view ↔ inside view: in two ZackD shorts sampled frame by frame (Nov 2026) the picture changed roughly every 2.5 s, cutting between a realistic person, X-ray anatomy and macro close-ups. Hard cuts are right for this format (unlike the build chain).
- Medical and science claims: only what a primary source or a reputable outlet states; no invented numbers ("pressure rises 20 times" — cut it unless you can cite it). A real case needs year + place + what happened, nothing you cannot source.
- Body horror is fine, gore is not: show anatomy schematically (X-ray, glowing tissue), never wounds.
- Idea bank: hold in a sneeze / a burp; swallow gum / a magnet / a fly; never blink; crack your knuckles; drink too much water; stop sleeping; get stung by [animal]; fall into [place]; what if the Moon disappeared / the Earth stopped spinning (use the X-ray language for planets: cutaway of the Earth).

## Titles
- Put the transformation in the title: "How a [start] Becomes a [end]" / "How you invented [X]" / "What happens if you [X]".
- 3–7 words, no clickbait the video doesn't deliver, no "AI" in the title.
- First frame = the start state already interesting (hole already dug, cave already dark) — no logo, no intro.
